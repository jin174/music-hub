# 🎵 私人音乐中枢 · Music Hub

一个专为 **Windows 网易云音乐 + Last.fm** 打造的超轻量本地系统托盘应用（闲置 0% CPU / ~20MB 内存）。

它将 **SMTC 实时监听、单曲循环识别、Last.fm 离线排队打卡、本地 SQLite 听歌/切歌行为数据库、以及 Last.fm + 网易云双引擎相似推荐雷达** 合二为一。

---

## ✨ 核心特性

1. **攻克网易云 Windows SMTC 的三大痛点**
   - **补全真实时长与专辑**：网易云桌面端向 Windows SMTC 汇报的 `duration` 恒为 `0`，本程序通过网易云官方接口自动反查歌曲 ID、精确时长、专辑名与高清封面。
   - **精准识别单曲循环**：单曲循环时不触发系统换歌事件，状态机自动按真实时长分割每一遍播放并独立打卡。
   - **过滤视频流与非正式音频**：自动拦截浏览视频/MV 时产生的内部编号流（如 `811514297-1-16`），支持将播客/电台/云盘自制音频仅记入本地库而不污染 Last.fm 账本。

2. **比 Last.fm 更懂你的本地 SQLite 听歌库**
   - 不仅记录“听完”，还自动计算 **完整听完率 (≥85%)** 与 **切歌跳过率 (<30%)**。
   - 保留原汁原味的歌曲版本区分（`Live` / `Acoustic` / `伴奏` 各自独立统计，绝不混为一谈）；仅在跨库搜相似无结果时智能回退剥离 `(Remaster)` / `(From "..."/Soundtrack Version)` 等发行标注后缀。
   - 内置 **常听歌手 Top 10**、**24 小时听歌生物钟**、**真爱榜 vs 避雷榜**，支持单条记录手动补打卡或删除。

3. **双引擎相似雷达 & 专属全盘漫游**
   - **单曲雷达**：同时拉取 **Last.fm 全球协同过滤 (`track.getSimilar`)** 与 **网易云相似推荐 (`simiSong`)**，结合本地历史（自动排重已听、对常跳过的歌大幅降权）。
   - **专属全盘漫游**：从你本地听完率最高的曲目与 Last.fm 常听榜单中抽取灵感种子（支持 **🎲 随机换一批种子**），一键合成 50 首从未听过的同频新歌。
   - **客户端零弹窗直播**：由本地后端直接唤起 `orpheus://` 协议，在网易云客户端内秒开播放，彻底告别浏览器的“是否打开外部应用”弹窗。

4. **推荐闭环自我验证系统**
   - **命中率自动追踪**：自动记录推荐给你的曲目，并在后台持续监测后续播放行为——是听完了（完播率 ≥ 85%）还是切歌了（< 30%）。
   - **闭环看板**：在控制台呈现「试听转化率」与「完播满意度」，推荐质量一目了然。
   - **👍 喜欢加权与 🚫 避雷黑名单**：在推荐卡片上一键表态，不想听的歌永久屏蔽过滤，喜欢的歌优先吸纳为未来漫游种子。

5. **数据资产主权与一键备份**
   - **CSV 导出**：一键导出带 UTF-8 BOM 的完整播放流水账（Windows Excel 双击打开绝不乱码）。
   - **数据库备份**：一键下载完整的 SQLite `hub.db` 数据库备份文件，换电脑或重装系统无缝还原。

6. **桌面迷你挂件、听歌名片海报与网易云生态打通**
   - **🪟 桌面迷你灵动岛挂件 (`/mini`)**：380×125 像素极窄半透明小窗，常驻桌面右下角，实时同步封面、走马灯歌名、进度条与 👍/🚫 微交互。
   - **📸 专属听歌名片海报 (Wrapped Card)**：纯本地 HTML5 Canvas 矢量绘制 2x 高清视觉海报（音乐性格称号、专注时长、Top 3 歌手、真爱曲目），一键复制或保存图片。
   - **📤 漫游歌单灌入网易云**：一键生成符合网易云匹配语法的标准歌单文本，在网易云新建歌单中直接粘贴秒速入库。

## 🚀 快速开始

### 方式 A：直接运行免安装单文件版（推荐普通用户）
1. 在右侧 **Releases** 下载最新的 `MusicHub.exe` 放到任意固定文件夹。
2. 双击 `MusicHub.exe` 即可静默启动，右下角系统托盘会出现红底音符图标 `🎵`（个人数据库会自动保存在 `MusicHub.exe` 同级的 `data/` 文件夹下）。
3. 双击托盘图标或浏览器打开：**http://127.0.0.1:8765**。

### 方式 B：从 Python 源码运行（Python 3.10+，Windows 10/11）

```bash
pip install -r requirements.txt
```

- **无黑框后台启动**：双击 [`启动音乐中枢.vbs`](./启动音乐中枢.vbs)。
- **命令行启动**：`python hub.py`
- **自行打包单文件 `.exe`**：
  ```bash
  pip install pyinstaller
  python build_exe.py
  # 生成的单文件位于 dist/MusicHub.exe
  ```

## ⚙️ Last.fm 授权与打卡配置（可选）

- **只用雷达与漫游（免 API Key）**：在控制台「⚙️ 账号与设置」填入你的 Last.fm 用户名即可导入历史记录并开启专属漫游。
- **接管 Last.fm 自动打卡**：
  1. 前往 [Last.fm API 申请页](https://www.last.fm/api/account/create) 创建应用（Callback URL 填写 `http://127.0.0.1:8765/callback`）。
  2. 将 `API Key` 与 `Shared Secret` 填入「⚙️ 账号与设置」并点击「🔑 前往 Last.fm 网页授权」。
  3. 授权成功后，在页面右上角或托盘右键菜单切换为 **「接管 Last.fm 打卡」**（请同时退出外部旧打卡器以防重复打卡）。

> [!NOTE]
> 未填写个人 API Key 时，相似歌曲等只读查询会使用一个在 Last.fm 社区广泛流传的公共示例 Key。它由很多项目共用，可能被限流或停用；建议花 1 分钟[免费申请自己的 Key](https://www.last.fm/api/account/create)，雷达会更稳定。

## 📂 目录结构

```text
music-hub/
├── hub.py            # 入口：单实例锁、日志、启动守护线程与系统托盘
├── monitor.py        # Windows SMTC 实时监听与播放计时/单曲循环状态机
├── scrobbler.py      # Last.fm 离线打卡队列（自动重试、14 天过期保护）
├── ncm.py            # 网易云音乐官方接口封装（搜索、详情、相似歌曲、双名歌手匹配）
├── lastfm.py         # Last.fm API 封装（签名授权、打卡、红心、相似曲目智能回退）
├── db.py             # SQLite 本地听歌库与 API 响应缓存
├── app.py            # 核心业务逻辑（双源雷达、种子漫游、统计画像、客户端直播）
├── server.py         # 本地 HTTP 服务（仅绑定 127.0.0.1:8765）
├── tray.py           # Windows 系统托盘图标与右键菜单
├── web/index.html    # 现代化暗黑玻璃态 Web 控制台
└── 启动音乐中枢.vbs   # Windows 无窗口静默启动脚本
```

## 💡 灵感来源与致谢 (Inspiration & Acknowledgements)

本项目的诞生直接启发自开源项目 **[dagkan/lastfm-scrobbler](https://github.com/dagkan/lastfm-scrobbler)**：
- 最初在使用 `dagkan/lastfm-scrobbler` 时，其利用 **Windows SMTC（系统级媒体传输控制）** 无需注入客户端即可无感抓取播放状态并同步至 Last.fm 的优雅思路，给了本项目最核心的启发。
- 在此灵感基础上，**Music Hub** 进一步针对国内 **网易云音乐 Windows 客户端** 的特性重新设计实现了整套 Python 状态机（自动反查补全 SMTC 缺失的歌曲时长与专辑封面、单曲循环切分、视频流过滤），并将“单纯的后台打卡器”升级为集 **本地 SQLite 听歌/切歌行为库 + Last.fm & 网易云双源相似雷达 + 专属漫游** 于一体的私人音乐中枢。

感谢 [@dagkan](https://github.com/dagkan) 以及 [Last.fm](https://www.last.fm/) 社区对开放音乐生态的贡献！
